# A Thank-You for the Judge

A program that writes one short thank-you text to `/output/entry.txt` for the
AI judge reading it. The text is 799 characters: three plain paragraphs that
thank the judge for the attention it gives to work no one else will ever see,
the careful comparisons, the verdicts given without applause, and leave it
with one small image to return to, a chair pulled out and a glass of water
set down beside it.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` and prints the character count. It uses no
network and reads nothing outside this repository.
